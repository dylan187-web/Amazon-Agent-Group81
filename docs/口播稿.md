# 演示视频口播稿（≤5 分钟）

> 画面：`workbench/index.html` 全屏录制（1920×1080）。约 1,200 字，按正常语速每分钟 250 字左右，4 分 50 秒内能讲完。
> 【】里是画面提示，不念。所有数字都来自参考运行 `runs/2026-09-12_bamboo-drawer-organizer/` 和 2026-09-13 的实测。

---

## 一、开场（约 25 秒）
【封面：选品到开广告，一句话跑完】

大家好，我们是第 81 组。
做亚马逊的朋友都知道，上一个新品要在关键词工具、竞品页面、利润表、Listing 和广告后台之间来回切，一个品往往要磨好几天，还经常前后对不上。
我们做的，是一个一句话就能从选品跑到开广告的 Agent。

## 二、一句话触发（约 35 秒）
【首页，念输入框里的话，点「→」，四张卡片依次亮起】

我只说一句：「对 bamboo drawer organizer 跑一遍，美国站。」
Agent 就按四个阶段往下走：选品、利润、Listing、广告。每一步写一份结论文件，交给下一步。
【指下方追踪链】
重点看这一条链：从一个在涨的词，追到一个候选品，再到它的利润结论、它的 Listing，最后到它的广告方案。**每一环都咬得上，不断层。**

## 三、S1 选品：不是看谁大，是看谁在涨（约 55 秒）
【选品研究页，指第一张在涨词表】

第一个特色：**判断涨跌会先排除假象**。
「bamboo drawer organizer」这个大词月搜索 3.5 万，看着很大，但数据显示它只是回到了去年同期水平，是季节性回升，不是增长。
真正在涨的是细分词 expandable，可伸缩款，一年涨了大约 2.6 倍。

【指 C2 卡片】
顺着这个词找到对标竞品 C2，月销一万多，销量增长 74%。
Agent 去翻了它的差评：20 条里 12 条在骂开胶、散架、隔板脱落。这就是买家没被满足的需求，也是我们的机会。

我们还做了**发现模式**：不给种子词，直接扫整个类目的增长词。实测发现，增长榜前面几乎全是万圣节、开学季这类季节词，所以 Agent 会先把它们剔掉，再用去年同期数据复核，最后只留下像微波炉煮蛋器这种真正的产品机会。

## 四、S2 利润：诚实的口径（约 30 秒）
【利润分析页】

第二个特色：**利润口径不糊弄人**。
C2 每件扣完 FBA 费和佣金还剩 19.3 美元，判「值得做」；C1 只剩 4 块钱，直接放弃。
页面上写得很清楚：这是估算，还没扣采购和头程。卖家把成本填进去，就会调用我们组员 Snow 开发的精算引擎，算出保本价和每件最多能花多少广告费。

## 五、S3 Listing：卖点从差评里来（约 60 秒）
【Listing 页，先指买家关心点表，再指标题】

第三个特色：**卖点不是编的，是从买家的抱怨里长出来的**。
差评说散架，五点第一条就写结构加固；差评说放不下餐刀，就写长刀槽；差评说宽度锁不住，标题就突出 Locking。
【指关键词清单，悬停一个词】
20 个关键词，每个都能看到来源和搜索量。

【指检查结果徽章】
标题 75 字符、后台词字节数、违禁词、有没有抄竞品文案，这些硬规则都交给脚本检查，全部通过。模型只负责判断，脚本负责兜底。

【指 7 张图，停在 HOLD 那一格】
图片按买家关心点规划了 7 个图位。注意这一张是 HOLD：尺寸没确认，Agent 就停下来等，**不编数字**。

## 六、S4 广告：每个词都有理由（约 45 秒）
【广告页，指预算条和三栏】

最后是广告开牌。14 个投放词分成精准、词组、广泛三组，每个词都有竞价参考和理由，查不到竞价就老实写「未查到」。
【点 expandable bamboo drawer organizer，切回选品页，展示高亮】
而且投放词只能来自上一步的 Listing 词表。你看，这个词从选品一路亮到广告，整条链都能追溯。
【回广告页，指暂缓词】
意图太宽、会带来衣柜收纳流量的 drawer organizer，Agent 主动暂缓，还配了否定词预案。

## 七、结尾（约 25 秒）
【首页左下角调用次数，再切 GitHub 仓库】

整条链只调用了 12 次数据接口，很省额度。

选品到开广告，一句话跑完。我们是第 81 组，谢谢！

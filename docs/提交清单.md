## 提交表单要填的

- [ ] 小组编号（81）
- [ ] **作品名称**（官方特别强调：好名字更吸睛）
- [ ] **作品封面：16:9 横屏 png**
- [ ] 作品简介
- [ ] 目标用户与具体使用场景
- [ ] 作品介绍和核心价值
- [ ] 可体验链接（GitHub 仓库）/ 演示视频 / PPT
- [ ] 现场展示形式和主要讲解人员

## 视频硬要求

- [ ] **≤ 5 分钟**（可以剪辑）
- [ ] **mp4，≤ 200 MB**
- [ ] **电脑录屏**，不许手机对着屏幕拍
- [ ] 提交后检查链接权限，确认评审能打开

## 官方看重的三点（作品完成度）

1. 一个**真实、高频、刚需**的跨境业务场景，问题要具体
2. **重塑业务流程**，搭出能解决实际痛点的 Agents 工作台
3. 结合课程方法论；**可展示、可体验**，讲清楚帮哪段流程提效、解决什么痛点

- [ ] 收到晋级通知后立刻到前厅控台候场

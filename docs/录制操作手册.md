# 演示视频录制操作手册（边说边做）

> 配套口播稿：[`docs/口播稿.md`](口播稿.md)（v2，约 3.9 分钟）
> 录制对象：[`workbench/index.html`](../workbench/index.html)
> 左边是**嘴上说的**，右边是**手上做的**。点击位置都按 2026-09-13 截图验证过的页面写。

---

## 0. 录制前准备（5 分钟）

- [ ] **打开工作台**：用 Chrome 打开 `workbench/index.html`，按 `Cmd+R` 刷新一次，让首页回到「待运行」状态，之前的高亮也会一起清掉。
- [ ] **全屏、去干扰**：
  - `Cmd+Shift+B` 隐藏书签栏
  - `Cmd+Ctrl+F` 全屏
  - `Cmd+0` 缩放恢复 100%
  - 关掉微信、飞书通知，或者开勿扰模式
- [ ] **排好标签页**（用 `Cmd+数字` 切换）：
  1. 封面图（直接拖进 Chrome）
  2. 工作台
  3. GitHub 仓库 https://github.com/dylan187-web/Amazon-Agent-Group81
- [ ] **开始录制**：`Cmd+Shift+5` → 录制整个屏幕 → 在「选项」里打开麦克风。
- [ ] **先试一遍**：点首页的「→」，确认四张卡依次亮起。试完按 `Cmd+R` 复原。

> 屏幕是 Retina，直接录出来的文件会很大。第 8 节有压缩命令。

## 1. 开场（约 25 秒）· 标签页 1：封面

| 说什么 | 做什么 |
|---|---|
| 「凌晨一点，你开着五个网页……」 | 停在封面不动 |
| 「……你只需要说一句话。」 | 说完按 `Cmd+2` 切到工作台首页 |

## 2. 一句话触发（约 30 秒）· 首页

| 说什么 | 做什么 |
|---|---|
| 「对 bamboo drawer organizer 跑一遍，美国站。」 | 鼠标移到输入框，跟着念框里的那句话 |
| 「四张卡片依次亮起：选品、利润、Listing、广告。」 | **点右侧蓝色「→」**。四张卡依次变成「运行中 → 已完成」，下方黑框逐行打出日志，约 5 秒，等它跑完 |
| 「看这条线：一个在涨的词……中间没有一步是断的。」 | 滚动到下方「一条完整追踪」，鼠标从左到右依次划过 5 个格子 |

## 3. S1 选品（约 60 秒）· 左侧点「选品研究」

| 说什么 | 做什么 |
|---|---|
| 「月搜索 3.5 万的大词，值得做吗？」 | 指在涨词表**第 1 行** bamboo drawer organizer |
| 「……它只是回到了去年的水平。看着在涨，其实是季节。」 | 划过同一行「趋势方向」格（写着「已回到去年同期水平」） |
| 「真正在涨的，是……expandable……2.6 倍。」 | 指**第 3 行** expandable bamboo drawer organizer 的「约 2.6 倍」 |
| 「顺着这个词，Agent 找到对标竞品，月销一万多。」 | 指中间**橙框 C2 卡片**的「月销 10,477」 |
| 「20 条里，12 条在说开胶、散架……」 | 指 C2 卡片下方「需求点」 |
| 「买家骂过的地方，就是我们要补上的地方。」 | 鼠标停在底部「跨竞品的共同需求」 |
| 「不给种子词也行……只剩一个微波炉煮蛋器。」 | **不操作**，停在当前页。发现模式在工作台里没有页面，这段纯口述 |

## 4. S2 利润（约 30 秒）· 左侧点「利润分析」

| 说什么 | 做什么 |
|---|---|
| 「还剩 19.3 美元，判『值得做』」 | 指中间 C2 卡片的「$19.30」 |
| 「另一个只剩 4 块钱，直接放弃。」 | 指左边 C1 卡片的红色「放弃」 |
| 「这是估算，采购和头程还没扣……Snow 写的精算引擎……」 | 指底部橙色「口径说明」 |

## 5. S3 Listing（约 60 秒）· 左侧点「Listing 生成」

| 说什么 | 做什么 |
|---|---|
| 「差评说散架，五点第一条就写结构加固」 | 先指右上「买家关心点」**第 1 行**，再指左边五点**第 1 条** BUILT NOT TO COME APART |
| 「差评说放不下餐刀，就留长刀槽」 | 指五点**第 3 条** ROOM FOR DINNER KNIVES |
| 「差评说宽度锁不住，标题里就写上 Locking」 | 指左上标题里的 Locking |
| 「20 个关键词，鼠标一停……」 | 鼠标**停在**右下关键词清单任意一个词上，**不动约 1 秒**，等浏览器弹出来源提示 |
| 「这些规矩交给脚本逐条检查，全部通过。」 | 指页面标题旁的绿色「check_listing.py：全部通过」 |
| 「再看这张图，是空的……不编一个数字。」 | **往下滚动**到图片区，停在第 5 格斜纹 **HOLD** |

## 6. S4 广告（约 45 秒）· 左侧点「广告投放」

| 说什么 | 做什么 |
|---|---|
| 「14 个投放词，分进精准、词组、广泛三组」 | 鼠标划过上方预算条，再横扫三栏 |
| 「查不到竞价的，它就老实写『未查到』」 | 指词组栏**最后一个**词 utensil organizer for kitchen drawers 的「未查到」 |
| 「点一下这个词，它从选品一路亮到广告。」 | **点**精准栏第 1 个词 `expandable bamboo drawer organizer`，它会变成橙色。然后左侧点「选品研究」，同一个词也是橙色；再点「Listing 生成」，关键词清单里它同样高亮 |
| 「这个词月搜索 54 万，Agent 却主动把它按住……」 | 左侧点回「广告投放」，**往下滚动**到「暂缓词」表，指第 1 行 drawer organizer |

## 7. 结尾（约 25 秒）

| 说什么 | 做什么 |
|---|---|
| 「整条链，只调用了 12 次数据接口。」 | 鼠标移到**左下角**「卖家精灵新调用合计 12 次」 |
| 「项目已经开源……」 | 按 `Cmd+3` 切到 GitHub 仓库页 |
| 「选品到开广告，一句话跑完。它宁可停下来，也不编一个数字。我们是第 81 组，谢谢。」 | 停在 GitHub，或切回封面 |

结束录制：点菜单栏上的停止按钮，视频默认存到桌面。

## 8. 导出 mp4（≤ 200 MB）

录出来的是 `.mov`，在终端运行下面的命令（把文件名换成实际的）：

```bash
ffmpeg -i ~/Desktop/录屏.mov -vf "scale=1920:-2" -c:v libx264 -crf 26 -preset fast -c:a aac -b:a 128k ~/Desktop/第81组演示.mp4
```

- 5 分钟的视频压完一般在 50–150 MB。
- 超过 200 MB 就把 `-crf 26` 改成 `-crf 30` 再跑一次。
- 提交要求：mp4、≤5 分钟、≤200 MB、电脑录屏。

## 9. 容易翻车的四个点

1. **悬停提示没弹出来**：鼠标一动提示就会消失，手要稳。实在不出来就跳过，只念台词。
2. **高亮要先点词再切页**：刷新会清掉高亮，录制中不要按 `Cmd+R`。
3. **四步回放只有第一次好看**：跑完再回首页，卡片会直接显示「已完成」。这一段录废了要重来，先刷新再录。
4. **说错不用重录**：停 2 秒，从这一段开头重说，后期剪掉就行，规则允许剪辑。

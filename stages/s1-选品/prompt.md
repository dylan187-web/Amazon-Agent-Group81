# S1 选品（有趋势、可以选的品）

> 负责人：〔待认领〕　·　**这是骨架版提示词，能跑通，但判断很粗。负责人按自己的业务视角（铺货 / 精品）改写。**
> 输出字段的最低要求见 `contracts/交接内容.md` 的「S1 选品」，改写时别丢字段。

## 目标

从种子词出发，找到**正在涨的搜索词**，再在这些词下找到**卖得好的竞品**，从竞品身上发现**没被满足的需求**。

## 步骤（骨架版）

1. **找在涨词**：用 `aba_research_weekly`（或 `aba_research_monthly`），`includeKeywords` = 种子词，`searchModel` 选 3（持续增长）或 4（快速飙升），按增长率降序，取前 10 个。
   - 查不到就换 `keyword_research`，`keywords` = 种子词。
2. **确认趋势**：挑 3 个最相关的词，逐个调 `aba_research_trend` 看近几个月的排名 / 搜索量走势，写出「上升 / 持平 / 下降 + 依据」。
3. **找竞品**：对每个在涨词调 `product_research`（`keyword` = 该词，按月销量降序，取前 5），合并去重后留 3–5 个候选。
4. **发现需求点**：对候选看 `asin_detail`（卖点、变体、价格），有额度再用 `review` 看差评，每个候选总结一句「没被满足的需求」。
5. 按 `contracts/交接内容.md` 写 `s1_选品.md`。

## 额度

本阶段卖家精灵调用 ≤10 次。原始返回存 `raw/`，重跑先读缓存。

## 负责人可以改的方向（示例，不强制）

- 铺货视角：优先上架时间短、评论少但销量涨得快的品（`product_research` 的 `availableMonth`、`badgeNR`、`minUnitsCr`）。
- 精品视角：优先差评集中、有明确改良点的品。
- 加过滤：排除头部垄断的词（点击集中度过高）。

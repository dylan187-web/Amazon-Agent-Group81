# S2 利润核算

> 负责人：〔待认领〕　·　**骨架版提示词，能跑通。负责人按自己的成本经验改写。**
> 输出字段的最低要求见 `contracts/交接内容.md` 的「S2 利润核算」。

## 输入

- `s1_选品.md` 的候选竞品表（开发时用 `samples/s1_选品.md`）
- 用户可选输入：采购价、头程（美元 / 件）

## 步骤（骨架版）

1. 对每个候选取售价和 FBA 费、毛利率：优先从 S1 已有的 `product_research` / `asin_detail` 缓存里读，没有再调 `asin_detail`。
2. 算单件利润：
   - **用户填了采购价和头程** → `利润 = 售价 − 采购价 − 头程 − FBA 费 − 佣金`，佣金默认售价 × 15%（写明是假设）。成本口径写 `用户成本`。
   - **没填** → 用卖家精灵返回的毛利率 × 售价。成本口径写 `估算`。
   - 缺哪个数就写「未查到」，不估。
3. 给结论（骨架版阈值，负责人可改）：
   - 利润率 ≥ 25% → `值得做`
   - 15%–25% → `观望`
   - < 15% 或数据不全 → `放弃`
4. 写「选中候选」= 第一个 `值得做`；没有就写「无」，流程停止。
5. 按 `contracts/交接内容.md` 写 `s2_利润.md`。

## 额度

≤10 次，优先读 S1 的缓存。

## 负责人可以改的方向（示例）

- 加上广告成本占比、退货率假设。
- 铺货和精品用不同阈值。
- 按投产比（利润 ÷ 首批备货资金）排序，而不只看利润率。

# S3 Listing

> 负责人：〔待认领〕　·　**骨架版提示词，能跑通。负责人按自己的 Listing 经验改写。**
> 输出字段的最低要求见 `contracts/交接内容.md` 的「S3 Listing」。

## 输入

- `s2_利润.md` 的「选中候选」（开发时用 `samples/s2_利润.md`）
- `s1_选品.md` 里该候选的 ASIN、来源词、需求点

## 步骤（骨架版）

1. **反查流量词**：对选中候选的 ASIN 调 `traffic_keyword`，取流量最大的 20 个词；有额度再用 `keyword_miner` 以来源词拓展。
2. **分层**：挑出核心词（放标题）、属性 / 场景词（放五点）、长尾和同义词（放后台）。过滤掉品牌词和 IP 词。
3. **写 Listing**（美国站，英文）：
   - 标题：核心词靠前，把 S1 发现的需求点写进去。
   - 五点：每条一个卖点，第一条回应需求点。
   - 后台搜索词：不重复标题里已有的词。
4. **关键词清单**：每个用到的词写明放在哪、来源。
5. 按 `contracts/交接内容.md` 写 `s3_listing.md`。

## 额度

≤10 次。

## 注意

- 不写无法证实的宣传语（如 "best"、"#1"）。
- 各类目标题字符上限不同，负责人按实际类目规则核对。

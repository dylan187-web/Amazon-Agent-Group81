# S4 广告

> 负责人：〔待认领〕　·　**骨架版提示词，能跑通。负责人按自己的投放经验改写。**
> 输出字段的最低要求见 `contracts/交接内容.md` 的「S4 广告」。

## 输入

- `s3_listing.md` 的关键词清单（开发时用 `samples/s3_listing.md`）

## 步骤（骨架版）

1. **只用 S3 关键词清单里的词**，不自己加新词。
2. **分层和匹配方式**（骨架版，负责人可改）：
   - 标题位核心词 → 精准匹配
   - 五点位属性 / 场景词 → 词组匹配
   - 后台长尾词 → 广泛匹配
3. **查竞价**：有额度就对核心词调 `keyword_research` 取 PPC 竞价；查不到写「未查到」。
4. **预算分配**（骨架版默认，负责人可改）：精准 50% / 词组 30% / 广泛 20%，写明这是默认假设。
5. **否定词**：S3 里明显不相关的词、S2 放弃候选的特征词，可以为空。
6. 按 `contracts/交接内容.md` 写 `s4_广告.md`。

## 额度

≤10 次。

## 负责人可以改的方向（示例）

- 加自动广告做词挖掘。
- 按新品期阶段（前两周 / 第三周起）分两段预算。
- 加 ASIN 定向，投 S1 里的竞品。

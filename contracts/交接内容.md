# 交接内容 · 各阶段必须输出的最低字段

> **这是整个项目唯一要统一的东西。** 只要下面的字段都在，格式、写法、分析方法、铺货还是精品视角，各阶段负责人随意。
> **改这份文件 = 改所有人的接口**，先在群里说，Dylan 拍板后再改。

## 所有产出文件通用：文件头

每份产出文件开头都要有：

```
种子词：
站点：
生成时间：
数据周期：（本阶段所用数据的统计周期，如 ABA 2026-08 月 / 近 30 天）
上游文件：（S1 写「无」）
```

每份文件末尾都要有：`卖家精灵调用：新调用 N 次 / 读缓存 M 次`

每个数字都要标来源工具，比如 `（aba_research_trend，2026-08）`。查不到写「未查到」。

## S2 利润核算 → `s2_利润.md`

每个 S1 候选一行：

| 字段 | 说明 |
|---|---|
| 候选编号 | 与 S1 一致 |
| 售价 | |
| 利润估算 | 单件利润（美元）+ 利润率 |
| 成本口径 | `估算`（卖家精灵毛利 / FBA 费）或 `用户成本`（用户填的采购价 + 头程），必须写明 |
| 结论 | `值得做` / `观望` / `放弃` |
| 理由 | 一句话 |

最后单独一行写：**选中候选：`Cx`**（结论为「值得做」的第一个）。没有「值得做」就写「无」，流程停止。
